PARASOL is the new name for the Data Science and Machine Learning Platform (DSMLP). The platform works exactly as it did. If you used DSMLP or Datahub before, you do not need to do anything.

## What stays the same


| You use | It is still |
|---|---|
| Datahub in a browser | [datahub.ucsd.edu](https://datahub.ucsd.edu), with your UC San Diego sign-in |
| The login node | `dsmlp-login.ucsd.edu` |
| The reservation app | [reserve.dsmlp.ucsd.edu](https://reserve.dsmlp.ucsd.edu/) |
| Launch scripts | `launch.sh`, `launch-scipy-ml.sh`, and the other launch commands, with the same flags |
| Your files | The same home directories, shared workspace space, and datasets |
| Workspaces and quotas | The same course, lab, and project workspaces, with the same limits |
| Support | [datahub@ucsd.edu](mailto:datahub@ucsd.edu) and the [ITS Service Desk](https://support.ucsd.edu/) |
| Policy | The same [conditions of use](/docs/reference/policy.html) |


Hostnames, container labels, and system messages still say `dsmlp`. Command output on the cluster also uses the old name. Both names refer to the same platform.

## What changes

- **The name.** Course pages, syllabi, and support replies will say PARASOL. Older material that says DSMLP is still correct.
- **The documentation home.** Every page of the DSMLP documentation now lives on this site, alongside the guides for each audience.
- **GPU capacity.** Four new GPU servers arrived with the name. See [Why PARASOL](/about/why-parasol.html).

## Where the old documentation went

Each page from the DSMLP documentation site has a matching page here. The [documentation index](/docs/index.html) keeps the same seven topics, and the audience guides moved to [Get Started](/get-started/index.html).

| DSMLP documentation | PARASOL page |
|---|---|
| Overview | [How PARASOL Works](/about/how-parasol-works.html) |
| Teaching with Datahub and DSMLP | [Teaching with PARASOL](/get-started/instructor-or-ta.html) |
| Research on DSMLP | [Research on PARASOL](/get-started/individual-researcher.html) |
| Other audience guides | The same titles under [Get Started](/get-started/index.html) |
| Technical documentation | The same titles under [Documentation](/docs/index.html) |

When the DSMLP documentation site is retired, its addresses will forward to these pages. Course materials that link to the old addresses will keep working.

## The glossary entry

The [glossary](/docs/reference/glossary.html) lists DSMLP as the former name of PARASOL. Datahub is the browser interface to the cluster, and the Research Cluster is the name the same cluster carries for research work.
